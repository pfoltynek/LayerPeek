# Security policy

## Supported versions

Only the latest release gets security fixes. Versions 0.x are previews.

## Reporting a vulnerability

Please **don't** report security issues in public issues, discussions or pull requests.

Use GitHub's [private vulnerability reporting](https://github.com/pfoltynek/LayerPeek/security/advisories/new)
instead. Please include:

- the app version (About window) and the operating system,
- what an attacker can do and under which conditions (local user, another device on the network, …),
- steps to reproduce or a proof of concept.

This is a hobby project maintained in free time. You should get a first answer within 14 days. Please give us a
reasonable time to release a fix before you publish details.

## Scope

In scope: the app itself, its local PrusaLink web proxy, the handling of stored passwords and the camera stream
decoding.

Out of scope: vulnerabilities in the printer firmware, PrusaLink, Prusa Connect or the cameras themselves. Please
report those to [Prusa Research](https://www.prusa3d.com/).
