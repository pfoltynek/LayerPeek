# Prusa Connect API – poznámky

> Zatím neprozkoumáno. Výsledek průzkumu doplní úkol **T-004**.

## Co zjistit

- Oficiální veřejné API pro uživatelské aplikace? Způsob přihlášení (Prusa Account, OAuth, API token)?
- Endpointy: seznam tiskáren, stav, úloha, telemetrie, kamera.
- Rate limity a podmínky použití.

## Zdroje

- https://connect.prusa3d.com
- https://github.com/prusa3d (hledat OpenAPI / SDK pro Connect)
